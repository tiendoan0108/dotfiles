# AeroSpace Keybindings

Modifier chính: **Alt** (Option)

---

## Layout

| Phím | Lệnh |
|------|------|
| `Alt` + `/` | Đổi layout tiles (horizontal / vertical) |
| `Alt` + `,` | Đổi layout accordion (horizontal / vertical) |

---

## Focus (di chuyển focus)

| Phím | Lệnh |
|------|------|
| `Alt` + `H` | Focus trái |
| `Alt` + `J` | Focus xuống |
| `Alt` + `K` | Focus lên |
| `Alt` + `L` | Focus phải |

---

## Move (di chuyển cửa sổ)

| Phím | Lệnh |
|------|------|
| `Alt` + `Shift` + `H` | Move trái |
| `Alt` + `Shift` + `J` | Move xuống |
| `Alt` + `Shift` + `K` | Move lên |
| `Alt` + `Shift` + `L` | Move phải |

---

## Resize

| Phím | Lệnh |
|------|------|
| `Alt` + `-` | Thu nhỏ (smart −50) |
| `Alt` + `=` | Phóng to (smart +50) |

## Move cửa sổ sang workspace

| Phím | Lệnh |
|------|------|
| `Alt` + `Shift` + `1` … `9` | Move node → workspace `1`–`9` |
| `Alt` + `Shift` + `A` … `Z` | Move node → workspace tương ứng (không có `H`, `J`, `K`, `L`) |
| `Alt` + `Shift` + `Tab` | Chuyển workspace sang monitor kế tiếp |

Workspace letter có binding move: `A B C D E F G I M N O P Q R S T U V W X Y Z`

---

## Service mode

Vào service mode: `Alt` + `Shift` + `;`

| Phím | Lệnh |
|------|------|
| `Esc` | Reload config → về main mode |
| `R` | Flatten workspace tree (reset layout) → main |
| `F` | Toggle floating / tiling → main |
| `Backspace` | Đóng mọi cửa sổ trừ cửa sổ hiện tại → main |
| `Alt` + `Shift` + `H` | Join với cửa sổ bên trái → main |
| `Alt` + `Shift` + `J` | Join với cửa sổ bên dưới → main |
| `Alt` + `Shift` + `K` | Join với cửa sổ bên trên → main |
| `Alt` + `Shift` + `L` | Join với cửa sổ bên phải → main |
| `↓` | Giảm volume |
| `↑` | Tăng volume |
| `Shift` + `↓` | Mute (volume = 0) → main |

---

## Ghi chú

- Không có binding cho workspace `H`, `J`, `K`, `L` (các phím đó dùng cho focus/move).
- Config: `aerospace.toml`
